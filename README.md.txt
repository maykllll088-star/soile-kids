# Сөйле Kids — логопедиялық сайт прототипі

Балаларға арналған қазақша логопедиялық оқу платформасының front-end прототипі.

## Ішінде не бар?

- Басты бет
- Бастапқы диагностика
- Дыбыстар бойынша сабақтар
- Артикуляциялық жаттығулар
- Мини-ойын
- Жетістіктер бөлімі
- Ата-аналарға арналған прогресс панелі
- Responsive дизайн
- Қарапайым браузерлік дыбыс синтезі

## GitHub Pages арқылы іске қосу

1. GitHub-та жаңа репозиторий ашыңыз.
2. Осы 4 файлды репозиторийге жүктеңіз.
3. `Settings` → `Pages` бөліміне кіріңіз.
4. `Deploy from a branch` таңдаңыз.
5. `main` тармағын және `/root` бумасын таңдаңыз.
6. `Save` басыңыз.

Бірнеше секундтан кейін GitHub Pages сайт сілтемесін береді.

## Маңызды

Бұл — front-end прототип. Қазіргі нұсқада:
- аккаунт/тіркелу жүйесі жоқ;
- деректер серверде сақталмайды;
- нақты AI логопед пен дауыс талдауы қосылмаған;
- ата-ана кабинеті демо-деректермен көрсетілген.

Кейін Firebase / Supabase, нақты авторизация, аудио жазу, логопед панелі және AI функцияларын қосуға болады.
